# About this repo

This is the codebase of the **Learn Spring Security course**. 

If you're already a student of the course - you can start exploring this through the lesson notes in the course.

Note that the code for each course module is hosted on its own branch, you'll have to switch to the branch corresponding to the module you're on, for example: `git checkout lsso-module1`

If you're not a student, you can get access to the course here: ["Learn Spring Security"](https://www.baeldung.com/course-lss-td7ng)
